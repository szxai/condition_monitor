# 工况监控系统 (PyQt 版) 使用说明

本程序基于 PyQt5 开发，提供了更现代化的用户界面和更丰富的功能。

## 启动方法

确保已安装 PyQt5：
```bash
pip install PyQt5
```

运行程序：
```bash
python gui_main_qt.py
```

## 功能特性

### 1. 界面布局
- **左侧面板 (执行状态)**:
  - **当前任务**: 醒目显示正在执行的工况名称。
  - **下个任务**: 提示即将执行的任务。
  - **执行详情**: 实时显示圈数进度、循环区状态。
  - **途经点**: 列表显示当前工况的关键点位及其通过状态（✔/✘）和时间，隐藏了具体的经纬度信息。
  - **控制按钮**: 跳过当前、人工完成、重置任务。

- **右侧面板 (任务队列)**:
  - 显示完整的任务列表及其状态（等待、执行中、已完成）。
  - **点击交互**: 点击任意任务（包括已完成的）可查看详细信息（ID、描述、开始/结束时间、完成原因等）。

### 2. 配置管理
- 点击工具栏的 **"⚙ 参数设置"** 按钮，可直接修改系统配置：
  - **GPS 模式**: 在 "csv" (调试/模拟) 和 "usb" (实时 GPS) 之间切换。
  - **CSV 文件**: 选择用于模拟的 GPS 数据文件。
  - **串口设置**: 配置端口号和波特率。
  - **自动跳过**: 调整距离和时间阈值。
  - **保存生效**: 修改配置后点击保存，重启程序即可生效。

### 3. 任务管理
- **人工完成**: 手动标记当前任务为完成。
- **重置任务**: 清除所有任务的完成状态，从头开始执行。
- **状态持久化**: 任务状态会自动保存，重启程序后可继续执行未完成的任务。

## 注意事项
- 修改配置（如 GPS 模式）后，必须重启程序才能生效。
- 确保 `config/tasks_list.json` 文件存在且格式正确。
